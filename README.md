# installing: 
```term
./configure && make && sudo make install
```
also, you'll need `ncurses-devel` to compile it

that's pretty much it lol

# IF IT FAILS
if for whatever reason `./configure` fails try running this
```term
make bigclean && autoconf && ./configure && make
```
you will need autoconf installed though
